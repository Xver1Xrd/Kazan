# Фото для меток на карте

Положи сюда картинки (jpg/png/webp) и укажи путь в `src/data.ts`
у нужной точки в поле `image`, например:

```ts
{ name: 'Казанский Кремль', lat: 55.7989, lng: 49.1064, emoji: '🏰',
  image: '/points/kremlin.jpg' },
```

- Путь всегда начинается с `/points/...`
- Если `image` не задан — на метке показывается эмодзи из поля `emoji`
- Картинки лучше квадратные (обрежутся по центру), ~200×200 достаточно
